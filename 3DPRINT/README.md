# サイドブレーキ用 万力式デスククランプ v5

Sim Racing Handbrake (Brake Mount) を机の天板端に挟んで固定するためのアフターパーツ。
本体の平面形状は台座のアウトラインを +5mm オフセットでトレース (57.2 × 134.7mm)。
押さえは中央1か所、締め付けは「ノブ＋ねじ一体成型」の印刷ねじ。材質は PETG。

設計ソース: 本体 `work/build_main_v5.py`、プラグ/クーポン
`work/build_plug_coupon_v5.py`、ねじ/インサート `gen_threads.py`、
印刷M6 `gen_m6.py`、輪郭抽出 `work/outline.py`。
(`desk_clamp.scad` は v3 時点のパラメトリック参考。現行の正は build_main_v5.py)

## v5 の変更点 (2026-11-16、v4 印刷後の指摘から)

- **支柱の溝を廃止**: v4 の溝は高さ3.2mmで標準M6ナット (5.0mm) が
  通らない上に、印刷時にサポートが詰まって除去できなかった。
  支柱はソリッドに戻し、強度も回復。
- **手前ナットはプレート裏の「スライドトンネル」方式** (本人の案を採用):
  手前のトラップ六角をそのまま後ろへ伸ばした六角トンネル
  (深さ6.2mm、穴中心から Y=31 まで) をプレート裏に彫る。
  ナットは支柱より後ろの開いた入口から上へ入れ、前へスライドさせると
  六角ソケットの斜面で X 方向がセンタリングされ、前面で止まる
  (中心は穴より 0.6mm 手前。残りはボルトが引き寄せて合わせる、
  奥2穴のトラップ内遊びと同じ量)。後ろから栓 (プラグ) を差して
  ナットを留める。プラグは荷重を受けない (搬送と保持だけ)。
- **金物が完全統一**: 3穴とも標準M6ナット＋同じ長さのボルトで済む。
- 本体より先に `test_coupon_v5.stl` (約13g) でスライドの渋さを
  検証できるようにした。

## v4 の変更点 (v3 の印刷フィードバックから)

- **向きを180°反転**: 三角 (1穴) 側が手前 (机の端側)、2穴側が奥。
  レバーは三角側へ引くのでこれが正向き。
- **支柱を増厚**: 机端の壁 12→20mm、顎 12→16mm。支柱の中にポケット類は入れない。
- **ポケット類を全部大きめに** (印刷誤差は本体側で吸収):
  インサート座 六角 AF31.2 / 座繰り Ø42 (インサート六角は AF29.2。
  AF30 では実印刷の座に入らなかったため 2026-11-17 に縮小)、
  M6 ナットトラップ AF11.2 × 深さ6.2、ボルト穴 Ø6.8。
- **前側1穴のナットは「後ろ差しドロワー式」** (2026-11-16 修正、**v5 で廃止**):
  溝の高さ3.2mmでは標準ナットが通らないため薄形ナットで逃がした案。
  v5 のスライドトンネルに置き換えられた。

## 仕組み

- C型クランプ本体の天板プレートに台座を載せ、台座の純正穴 (3× Ø6.5) で共締め。
- 奥の2穴: ナットはプレート裏の六角トラップに下から入れる (従来通り)。
- 手前の1穴: 標準ナットをプレート裏トンネルの入口 (支柱の後ろ) から
  上へ入れ、前へスライドさせて六角ソケットに座らせる。後ろから
  プラグを差して留める。締結力の経路は奥2穴と完全に同じ
  (ナットはトラップ天井に座る。プラグは荷重を受けない)。
- 机へは下側の顎に入れたナットインサート (印刷雌ねじ) に一体成型のノブねじをねじ込み、
  先端のパッドを天板裏に押し当てて挟む。押さえは中央1か所。
- 対応する天板厚: 約12〜45mm。顎の奥行きは端面から70mm、開口は50mm。
  天板端の下面に幕板がある机は干渉しないか要確認。

`desk_clamp_main.stl` は使用姿勢の参考用。印刷には `_print` 版を使うこと。

### 本体の印刷向き (重要)

`desk_clamp_main_print.stl` は **プレートの上面をベッドに貼る「逆さま」** 向き。

- ベッド接触はプレート全面 (約70cm²) なのでブリム不要、反りにも強い
- ポケット類 (ナットトラップ、スライドトンネル) は全部上向きに開くのでサポート不要
- サポートが要るのは **顎の下面だけ** (C字の内側の空洞に立つ天井部分)。
  空洞は両側面が開いているので、サポートは横から抜ける
- サポートはツリーより通常 (グリッド) が安定。上面Z距離 0.2mm 程度
- 横倒し (側面を下) は不可: 台座トレース輪郭の側面は曲面で、ベッドに触れるのは
  一番幅の広い帯だけになり、サポートも本体も不安定になる
- ベッドの跡が付くのはプレート上面だが、そこは台座に隠れる面なので問題なし

### 推奨設定

- 本体: ウォール6〜8周、インフィル40〜50% (ジャイロイド)。剛性が欲しければウォール多めが効く
- ねじ/インサート: ウォール4周、インフィル60%以上、レイヤー高さ0.12〜0.2mm
- プラグ/パッド/クーポン: ウォール4周、インフィル40%

ねじが渋い/緩い場合: `gen_threads.py` の `CLEARANCE` を調整して再生成。

## 台座固定の金物 (どちらか)

金属: **3穴とも同じ**。M6 ナット ×3 + ボルト M6×25〜30 ×3。
(M6×20 でも可。手前1本のみ、先端がトンネル床に当たるため頭下に
平ワッシャー1枚が必要)
印刷: `desk_clamp_nut_m6.stl` ×3 (AF10.9)、
ボルトは `desk_clamp_bolt_m6.stl` ×3。
後から金属 M6 に替えることも可能 (穴・トラップ寸法は金属基準)。
※印刷ナットは対角 12.6mm あり、トンネル (幅12.9mm) を通すと
片側0.17mmと渋い。手前は金属ナット推奨 (奥2穴は印刷でも可)。

印刷ボルト/ナットの注意: 締め付けは手締め＋1/8回転まで。PETG はクリープで
軸力が抜けるので増し締め前提。破断目安や詳細は v3 版の説明を引き継ぎ
(ボルト谷径 Ø5.2 で破断 450〜650N 程度の推定)。

## 組み立て

1. ナットインサートを顎上面の座繰り＋六角ポケットに上から落とす。
2. 下からノブねじを通し、先端にパッドをはめる。
3. 奥2穴のナットをプレート裏のトラップに入れる。
4. 手前1穴: ナットをトンネル入口 (支柱より後ろの開いた部分) から
   上へ入れ、指で前へスライドさせる。プラグを後ろから差し込んで
   ナットをソケットまで押し込み、そのまま留める。
   ※机に付ける前に済ませておくこと。
5. クランプを机の端に差し込み、台座を載せて (三角側が手前)、
   上からボルトを締める (3本とも同じ長さ)。
6. ノブを締めてパッドを天板裏に押し当て、固定する。

## 注意

- 押さえ1か所なので、レバーは真っ直ぐ引くのが前提。横方向にこじると台座ごと傾きやすい。
- 初回は弱い力から試してガタやズレがないか確認すること。
- 締め付けすぎは天板 (特に化粧板や中空フラッシュ構造) を傷める。パッド面全体が当たっているか確認を。
- 印刷ねじは金属ねじより弱い。締め付けは「パッドが潰れず、叩いてもズレない」程度まで。
- 手前ナットを外すときは、プラグ後部の指掛け窪みに指先を掛けて
  後ろへ引き、入口 (11mmの開口) から下へ抜く。次にナットを後ろへ
  スライドさせて入口から落とす。
- プラグ下面はプレート裏面と同一面 (z=0) で、机側へは一切出っ張らない
  (v1 のツマミは天板に当たるため廃止。窪みは上面側に掘ってある)。
- 旧ドロワー類 (先端差し凹み式・薄形用後ろ差し式) はいずれも廃止。
  印刷済みは使わないこと。
